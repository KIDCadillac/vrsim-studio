# VRSIM Studio

基于 iiQWorks.Sim 与 OpenXR 的个人 VR 虚拟调试研发项目，探索在头显中沉浸式查看和操作现有三维仿真场景，并逐步支持虚拟调试。

## 项目与仓库

项目于 **2026 年 9 月**开始探索，早期 VR 记录可追溯至 **9 月 22—23 日**。本仓库于 **2026 年 10 月 12 日（UTC+8）**建立，用于统一管理源码版本、软件包对应关系和开发验收进度，便于持续迭代与协作。

## 当前进度

- 已打通原生场景、双眼立体画面和头部随动；4K 测试路径为每眼 4096×4096，最近一次有效的 120 秒性能测试约 114 个新内容帧/秒。
- 已安装软件包基线为 0.1.4.0；4K 路径仍属于研发测试版本。
- 正在优化运动时的边缘闪烁、摩尔纹和画面稳定性，120 帧及完整交互体验尚未完成验收。

## 使用范围

当前为个人兴趣研发，开发与验收使用已有合法许可证的 **iiQWorks.Sim**。目前没有独立 Visual Components 许可证，也未完成其独立宿主兼容性验收。Visual Components 相关名称仅用于说明 SIM 的底层技术依赖。

当前版本未用于商用；未来商用版本另行规划。使用或构建本项目仍需自行具备宿主软件、SDK 和相关依赖的合法使用资格。第三方代码的来源与许可证单独保留。
