# VRSIM Studio

一个基于 iiQWorks.Sim 与 OpenXR 的个人 VR 虚拟调试研发项目。理念来自早期与 ChatGPT 的讨论：以现有三维布局为主场景，复用 SIM 的场景与渲染，让用户在头显中查看、操作仿真布局，并逐步进行程序调试。桌面和 VR 共同参与同一场景的工作流程。

工业仿真的 VR 方向已有成熟先例：Visual Components 在 [2017 年介绍了 Experience VR](https://www.visualcomponents.com/blog/introducing-visual-components-experience-2/)，并于[同年公开发布](https://www.visualcomponents.com/blog/check-out-whats-new-in-visual-components-4-0-5/)。本项目沿着这一方向学习和实践，重点在已有 SIM 环境中的原生场景复用与个人交互体验。

## 与官方 VR 项目的关系

| 项目 | 定位与用途 |
| --- | --- |
| Visual Components Experience／官方交互 VR | 已有的仿真 VR 产品与工作流程；[官方交互教程](https://academy.visualcomponents.com/lessons/introduction-to-interactive-vr/)包含组件抓取、关节点动与 HMI 操作。 |
| VRSIM Studio | 基于当前 iiQWorks.Sim 环境进行个人研发，目标是在头显内完成虚拟调试，并探索适合自己的操作与调试流程。当前处于画面质量、性能和交互验证阶段。 |

后续计划接入独立的外部 AI 服务，让用户在头显里直接说话，操作仿真中的现场布局并辅助程序调试。这是规划方向，尚未实现或通过验收；与官方已有功能的重合部分会据实记录。

## 当前进度

4K 测试路径已达到每眼 **4096×4096**，最近有效的 120 秒测试约 **114 个新内容帧/秒**。运动时的边缘闪烁、摩尔纹及画面稳定性仍在优化；120 帧和完整操作体验尚未通过验收。已安装软件包基线为 **0.1.4.0**，高分辨率路径属于研发测试版本。

## 构建与打包

C# 部分使用 .NET Framework 4.8／Roslyn，C++ 部分使用 MSVC／Windows SDK。**iiQWorks.App Builder** 用于插件应用打包，生成 `.kop`；SIM SDK／API 用于访问宿主场景，OpenXR 用于对接 VR 运行时。依赖及当前构建限制见 [构建说明](docs/BUILDING.md)。

## 使用范围

当前为个人兴趣研发，使用已有合法许可证的 **iiQWorks.Sim**。目前没有独立 Visual Components 许可证，其独立宿主兼容性尚未验收。当前版本未用于商用，未来商用版本另行规划。宿主软件与 SDK 由使用者合法安装，第三方代码保留各自来源和许可说明。
