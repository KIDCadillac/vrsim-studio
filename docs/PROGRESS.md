# VRSIM 开发与测试进度

VRSIM 是运行在 iiQWorks.Sim 内部的 XR 插件，探索将当前仿真场景以实时双目画面呈现在头显中。项目仍在开发与验证阶段。

## 近期真机测试环境

- 头显：Meta Quest 3
- 连接：USB 有线 Quest Link
- 主机系统：Windows
- 仿真软件：iiQWorks.Sim Advanced 1.3
